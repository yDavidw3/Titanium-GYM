# Titanium-GYM

Aplicação desktop de um sistema de academia (criando e gerenciando alunos e funcionários).

## Tecnologias e Dependências

* **Ambiente de Execução (IDE):** Eclipse IDE
* **Tecnologia/Framework de UI:** Java Swing
* **Componente de Janela Principal:** JFrame
* **Componente de Avisos/Diálogos:** JOptionPane
* **Estilização:** Look and Feel (L&F)
